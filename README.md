# Consulting Report Quarto Template

This template is for Quarto, which is similar to R Markdown, for R Studio. This template is based on the JSS style report with a few modifications, including smaller page margins, and a removed cover page header to allow for more space for the document itself.

This template was created for the ST 597 Statistical Consulting course at the University of Alabama.

To get started, open template.qmd and modify it with your code and body text for your report. Note that bibliography and citations can be handled automatically.
